# Car Detailing WhatsApp Chatbot Flow

## Objective
Create a WhatsApp chatbot that helps customers:

1. Greet the bot.
2. Select their car category.
3. View available services.
4. View service price and details.
5. Book an appointment.

---

# Flow Overview

```
User
   │
   ▼
Greeting Detection
   │
   ▼
Welcome Message
   │
   ▼
Select Car Category
   │
   ▼
Display Services
   │
   ▼
Select Service
   │
   ▼
Show Price + Service Details
   │
   ▼
Book Appointment
   │
   ▼
Collect Customer Details
   │
   ▼
Confirmation
```

---

# Step 2 – Vehicle Selection

Store selected vehicle in:

```
car_category
```

Example

```
car_category = SUV / MPV
```

After selection display all available services for that category.
